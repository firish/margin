# Paper build

```bash
uv run margin prevalence && uv run margin controls   # small result files the report reads
uv run margin report          # regenerate figures/ and tables/ from results/
cd paper && tectonic -X compile main.tex
```

- `main.tex` uses a TMLR-like article layout; for a TMLR submission swap the preamble for the official `tmlr.sty`.
- `tables/*.tex` and `figures/*.pdf` are generated by `margin report`; do not edit them by hand.
- `references.bib`: every entry verified on Crossref, arXiv or the live URL, 2026-10-11 to 2026-10-14 (see `references_verification.md`).
- `sections/prompt_*.txt` are rendered from the harness (AnnoMI client example).
