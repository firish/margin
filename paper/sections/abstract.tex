\begin{abstract}
Model-assisted qualitative coding saves effort only if we know which model decisions a human must still check. We ask whether
model confidence can select low-error decisions in fixed-codebook coding. Under a prospectively specified analysis plan, we
compare seven decision models, APIs that return probabilities for typed questions, with twelve LLM confidence signals on five
human-coded tasks: moral foundations in Reddit comments, motivational-interviewing dialogue and K-12 classroom talk. Raw
error ranking varies widely, with the open Kev-27B and Claude Sonnet's verbalized confidence best; recalibrating per
predicted code narrows most differences, and low calibration error alone does not predict useful selection. A threshold
fitted to 5\% error on calibration data exceeds 5\% on held-out data in about half of re-splits on Reddit comments for most
decision models, and thresholds do not transfer across codebooks. A Learn-then-Test rule that treats decisions as independent
also fails, because codes and utterances share comments and transcripts. A version that needs only a random sample of
hand-coded units bounds the error on the rest of the corpus. After 30\% of Reddit comments are hand-coded, it certifies
60--83\% of the remaining code decisions for most coders, nearly all of them calls that a code does not apply. On dialogue,
with whole transcripts hand-coded at the same budget, it certifies nothing, and could not even for a perfect coder; sampling
single utterances removes that obstacle but yields almost no certificates. Without a guarantee, a baseline that reads no text
accepts 75\% of comment decisions at 3.6\% error. Model uncertainty tracks annotator disagreement, and option order changes
some models' labels. All models were called on 10--12 October 2026; we release the harness and every model output.
\end{abstract}
